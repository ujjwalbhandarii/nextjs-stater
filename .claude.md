# .claude.md: Claude Agent Pre-Coding Rules

> **MANDATORY FOR CLAUDE & ALL AI AGENTS BEFORE CODING**

Please review and strictly follow the protocol defined in [`AGENTS.md`](AGENTS.md) and [`CLAUDE.md`](CLAUDE.md):

1. **Package Manager**: Use **Bun** ONLY (`bun dev`, `bun run build`, `bun run typecheck`, `bun run check`, `bun test`, `bun run format`).
2. **Architecture**: Domain features live in `src/feature/<feature-name>/`. App Router pages (`src/app/`) are thin shells rendering `src/feature/<feature-name>/index.tsx`.
3. **Feature README Mandate**: EVERY feature folder MUST contain a `README.md` file documenting domain logic, hooks, services, and components for AI searchability.
4. **Static Asset Placement Mandate**: Organize static assets into clean subfolders in `public/` (e.g., `public/images/`, `public/icons/`). Never leave loose files at `public/` root.
5. **Primitives**: UI primitives live in `src/components/ui/` using `cva`, `cn()`, and `@radix-ui/react-slot` (`asChild`).
6. **Hook & Service Separation (MANDATORY)**: Extract state to custom hooks in `hooks/` and backend logic to `services/`. Presentational JSX components MUST NOT contain inline business/state logic.
7. **Service Unit Testing Mandate**: Every service file in `services/` MUST have an accompanying unit test file (`<service-name>.test.ts`) tested via `bun test`.
8. **No Em Dash Rule**: NEVER use the em dash "—" symbol anywhere in code, markdown, comments, or docs. Use hyphens "-", colons ":", or clean punctuation.
9. **Post-Coding Verification**: Always execute `bun run verify` (`typecheck` + `check` + `lint` + `test`) after modifying code.
