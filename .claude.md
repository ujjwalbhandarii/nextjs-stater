# .claude.md - Claude Agent Pre-Coding Rules

> **MANDATORY FOR CLAUDE & ALL AI AGENTS BEFORE CODING**

Please review and strictly follow the protocol defined in [`AGENTS.md`](AGENTS.md) and [`CLAUDE.md`](CLAUDE.md):

1. **Package Manager**: Use **Bun** ONLY (`bun dev`, `bun run build`, `bun run typecheck`, `bun run check`, `bun run test`, `bun run format`).
2. **Architecture**: Domain features live in `src/feature/<feature-name>/`. App Router pages (`src/app/`) are thin shells rendering `src/feature/<feature-name>/index.tsx`.
3. **Primitives**: UI primitives live in `src/components/ui/` using `cva`, `cn()`, and `@radix-ui/react-slot` (`asChild`).
4. **Hook & Service Separation (MANDATORY)**: All stateful logic, API calls, and handlers MUST be extracted to custom hooks (`src/feature/<feature-name>/hooks/`). Backend services MUST live in `services/`. Presentational JSX components MUST NOT contain inline business/state logic.
5. **Service Unit Testing Mandate**: Every service file in `services/` MUST have an accompanying unit test file (`<service-name>.test.ts`) tested via `bun test`.
6. **Design System**: Use Tailwind CSS v4 OKLCH semantic tokens (`bg-background`, `text-foreground`, `bg-primary`, `border-border`). No hardcoded colors.
7. **Post-Coding Verification**: Always execute `bun run verify` (`typecheck` + `check` + `lint` + `test`) after modifying code.
